# Learning scripts

Standalone exercises written while building the project. Run from the repository root (they read `.env`).

- `01_gemini_api_basics.py` — send one prompt to Gemini and print the reply (no grounding).
- `02_manual_tool_calling.py` — the function-calling loop done by hand: tool request, run tool, return result, final answer.
- `03_embeddings_similarity.py` — embed a question and sentences, rank them by cosine similarity (including across languages).
